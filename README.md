# Sentrivo

Sentrivo is a web monitoring dashboard designed to help developers and businesses monitor the health, availability, and performance of their websites and web services from a single interface.

The goal of Sentrivo is to provide a simple, modern, and reliable platform for tracking website uptime, response times, SSL certificates, and other key metrics.

> 🚧 Sentrivo is currently under active development.

## Tech Stack

### Frontend
- HTML5
- CSS3
- JavaScript (ES6)

### Backend
- Node.js
- Express.js

### Database
- PostgreSQL

### Authentication
- JWT
- bcrypt

## Planned Features

- 📈 Uptime & response time tracking
- 🚨 Real-time alerts
